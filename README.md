# 📱 تطبيق المحمد (Al-Muhammad Islamic App)

تطبيق إسلامي شامل ومفتوح المصدر مبني باستخدام **React Native (Expo)**، تم تصميمه كنسخة احترافية بديلة لتطبيق "كهف" وبسورس كود كامل ومتاح للتعديل والتطوير الحر.

---

## ✨ الخصائص والمميزات الرئيسية

### 1. 📖 القرآن الكريم كاملاً
- فهرس كامل لـ **١١٤ سورة مباركة** (مكية ومدنية) مع عدد الآيات والمعاني باللغة الإنجليزية.
- شريط بحث سريع وفوري بالاسم أو برقم السورة مع فلاتر (الكل / مكية / مدنية).
- صفحة قراءة الآيات بخط عثماني وتنسيق إسلامي مريح للعين مع أرقام الآيات في أشكال زخرفية.
- التحكم الكامل في **حجم الخط (أ+ / أ-)** للقراءة المريحة.
- دعم الاستماع للتلاوة الصوتية مع قائمة بأشهر قراء العالم الإسلامي (مشاري العفاسي، عبد الباسط عبد الصمد، محمود خليل الحصري، السديس، وغيرهم).
- حفظ العلامات المرجعية والتفسير الميسر لكل آية.

### 2. 🕌 مواقيت الصلاة الدقيقة
- حساب فلكي دقيق بالمعادلات الرياضية الفلكية (موضع الشمس، زاوية الشفق، معادلة الوقت).
- دعم **٥ طرق حسابية معتمدة عالمياً**:
  - الهيئة المصرية العامة للمساحة
  - أم القرى - مكة المكرمة
  - رابطة العالم الإسلامي (MWL)
  - الجمعية الإسلامية لأمريكا الشمالية (ISNA)
  - جامعة العلوم الإسلامية بكراتشي
- دعم مذهب صلاة العصر (شافعي/جمهور vs حنفي).
- بطاقة الصلاة القادمة مع عداد تنازلي دقيق.

### 3. 🧭 بوصلة القبلة الذكية (Smart Qibla Compass)
- تحديد زاوية اتجاه الكعبة المشرفة بدقة بناءً على إحداثيات الموقع (Great Circle Bearing).
- حساب المسافة بالكيلومترات إلى مكة المكرمة.
- بوصلة رسومية تفاعلية تتغير ألوانها عند محاذاة الهاتف مع اتجاه القبلة.
- وضع محاكاة ومعايرة سهل للاختبار بدون حساسات.

### 4. 📿 حصن المسلم والأذكار اليومية
- بيانات حقيقية وموثقة من كتاب **حصن المسلم**:
  - أذكار الصباح (١٢ ذكراً)
  - أذكار المساء (١٢ ذكراً)
  - أذكار بعد الصلاة (١١ ذكراً)
  - أذكار النوم (٧ أذكار)
  - أذكار الاستيقاظ (٤ أذكار)
  - أدعية متنوعة ومأثورة (٨ أدعية)
- عداد تفاعلي لكل ذكر مع شريط تقدم الإنجاز لكل فئة.
- إمكانية إعادة ضبط العدادات في أي وقت.

### 5. 📿 السبحة الإلكترونية الرقمية
- عداد تسبيح ذكي وسريع في الصفحة الرئيسية مع اهتزاز لمسي (Haptic Feedback) عند إتمام الدورة.
- خيارات أذكار سريعة (سبحان الله، الحمد لله، لا إله إلا الله، الله أكبر، أستغفر الله).
- أهداف متغيرة (٣٣، ١٠٠، ١٠٠٠) مع تتبع إجمالي التسبيحات.

### 6. ⚙️ تخصيص كامل وخالٍ من الإعلانات
- خالي تماماً من أي إعلانات تجارية ١٠٠٪.
- دعم الوضع الليلي الداكن والوضع الفاتح.
- إمكانية تعديل السورس كود بالكامل وإضافة أي خصائص جديدة بسهولة.

## 🚀 طريقة تشغيل التطبيق وتجربته

### ١. المتطلبات:
- تثبيت [Node.js](https://nodejs.org/) (موجود لديك بالفعل).
- تطبيق **Expo Go** على هاتفك (متوفر مجاناً على Google Play أو App Store).

### ٢. تشغيل التطبيق في وضع التطوير:
افتح موجه الأوامر (Terminal / PowerShell) داخل مجلد المشروع:
```bash
cd C:\Users\Admin\.gemini\antigravity\scratch\AlMuhammad
npx expo start
```
سيظهر لك رمز **QR Code** في شاشة الـ Terminal:
- على **Android**: افتح تطبيق Expo Go وامسح الـ QR Code بكاميرا التطبيق.
- على **iOS**: افتح تطبيق الكاميرا العادي وامسح الـ QR Code واضغط على فتح في Expo Go.

## 📦 استخراج ملف التثبيت (APK) لنشره وتثبيته على الموبايل

إذا أردت إنشاء ملف `apk` لتثبيته مباشرة على أي هاتف أندرويد بدون Expo Go:
1. قم بإنشاء حساب مجاني على [expo.dev](https://expo.dev).
2. قم بتسجيل الدخول وبناء التطبيق عبر أمر:
```bash
npx eas-cli login
npx eas-cli build -p android --profile preview
```
ستحصل على رابط تحميل مباشر لملف الـ APK لتثبيته أو توزيعه على أصدقائك!

## 🛠️ كيفية التعديل والتخصيص:

- **تغيير الألوان**: افتح ملف `src/styles/theme.ts` وعدل `primary` أو `secondary`.
- **إضافة أذكار جديدة**: افتح ملف `src/data/azkar.ts` وأضف أي ذكر أو دعاء جديد داخل الفئة المناسبة.
- **تغيير اسم التطبيق وأيقونته**: من خلال ملف `app.json`.
